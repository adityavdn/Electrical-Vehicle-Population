## 📖 Overview

Exploratory data analysis of electric vehicle (EV) population trends, adoption rates, geographic distribution, and market insights. Analyzes EV registration data to identify patterns and predict future adoption.

## 🎯 Objectives

- Analyze EV population growth trends
- Geographic distribution analysis
- Make and model popularity assessment
- Electric range analysis
- Market penetration insights

## 🛠️ Technologies

- Python, Pandas, NumPy
- Matplotlib, Seaborn, Plotly
- Statistical Analysis
- Jupyter Notebook
